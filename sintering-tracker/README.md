# GAUSS 소결조건 기록 시스템

가스 소결로 SOP를 그대로 데이터화한 구글시트 기반 기록 프로그램입니다.
「가우스 잉크 Lot No 관리 시스템」과 같은 구조(Runs / Steps / Images / ActivityLog / Config,
소프트 삭제, 작성자 자동 기록)로 만들어서, 잉크 Lot No → 소결 런 → 결과까지 이력이 이어집니다.

## 시트 구성 (자동 생성)

| 시트 | 내용 |
|---|---|
| `Runs` | 런 1건당 1행. 소재·Lot·가스·퍼징·안전체크·가스예산·결과 |
| `Steps` | 런별 소결 프로그램 스텝 (구간명 / 목표온도 / 승온시간 / 승온속도 / 유지시간) |
| `Images` | 사진 (RunNo, FileId, 구분: 장입·결과·기타) — 파일은 드라이브 폴더에 저장 |
| `ActivityLog` | 누가 언제 무엇을 기록했는지 감사 로그 |
| `Config` | 관리자 이메일, 기본 봄베 용적, 최소 여유율, 잉크시트ID |

런 번호 형식: `SR-260909-01` (잉크 Lot `GI-CU-260828-01` 과 대응)

## 프로그램이 자동으로 해주는 것

- **가스 예산 검산** (SOP §6, 과거 Cu 산화 사고의 원인)
  가용량 = 봄베용적 × 1차압 × 0.9 / 필요량 = 상시유량 × 총 사이클시간
  여유율이 1.5배(야간 무인 2.0배) 미만이면 빨간 경고 + 낮춰야 할 유량을 계산해서 알려줌
- **승온속도 자동 계산** — 스텝별 ℃/min 을 표시해 컨트롤러 입력값 검증
- **소재별 안전 규칙** — Ti/Nb에 H₂ 가스 선택 시 차단 경고, 알루미나 세터 경고, 퍼징 횟수 부족 경고
- **과거 런 불러오기** — 성공한 런의 프로그램을 그대로 복사해 다음 런 출발점으로 사용
- **사진 업로드** — 장입/결과/기타로 구분, 드라이브 저장 후 이력 표에 썸네일 표시

## 설치

`설치 매뉴얼` 아티팩트 참고 (또는 아래 요약).

1. 구글드라이브 → 새 **구글 스프레드시트** 생성 (이름: `GAUSS 소결조건 기록`)
2. `확장 프로그램 > Apps Script`
3. `Code.gs` 내용 전체 붙여넣기 (기존 내용 삭제)
4. `+` → **HTML** → 파일명 `Index` (확장자 없이) → `Index.html` 내용 붙여넣기
5. 저장 → 함수 목록에서 `setup` 선택 후 **실행** → 권한 승인 (시트 5개 + 사진 폴더 생성됨)
6. `배포 > 새 배포 > 유형: 웹 앱` / 실행: 나 / 액세스: 나만 → URL 복사
7. 브라우저에서 URL 열고 `⋮ > 저장 및 공유 > 바로가기 만들기` → 바탕화면에 설치

## 잉크 Lot No 시스템과 연결

`Config` 시트에 아래 행을 추가하면 Lot No 입력칸에서 잉크 시트의 Lot 목록이 자동완성됩니다.

| 키 | 값 |
|---|---|

## 항목 추가/수정 시

`Code.gs`의 `RUNS_HEADER` / `STEPS_HEADER` 와 `Index.html`의 입력 필드를 함께 수정한 뒤
`배포 > 배포 관리 > 연필 아이콘 > 버전: 새 버전 > 배포` 를 하면 같은 URL로 갱신됩니다.
