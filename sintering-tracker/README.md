# GAUSS 소결 기록

소결 조건·부품별 수축률·사진을 쌓아가는 Apps Script 웹앱입니다.
「가우스 잉크 Lot No 관리 시스템」처럼 바탕화면 바로가기로 열어 씁니다.

데이터는 기존 **「소결 데이터」 시트**에 바로 쌓입니다. 그 시트에는 이미
슬라이서가 출력 작업을 자동 등록하는 `Jobs` 와, 비어 있던 `SinterBatches` · `Parts` 표가 있어서
**출력 작업 → 소결 배치 → 부품별 결과**가 한 줄로 이어집니다.

## 시트 구조

| 시트 | 내용 | 이 프로그램이 하는 일 |
|---|---|---|
| `Jobs` | 슬라이서가 자동 등록한 출력 작업 | 읽기. 소결 상태를 「완료」로 저장하면 연결된 작업을 `소결완료`로 표시 |
| `SinterBatches` | 소결 1회 = 1행 | 기존 18개 열은 그대로 채우고, 상태·소재·Lot·스텝 표·가스 예산 등은 뒤에 열을 추가 |
| `Parts` | 부품별 소결 전/후 치수·무게 | 수축률(X/Y/Z)·감량률 자동 계산, 판정, 사진 링크 |
| `Photos` | 사진·로그 파일 목록 (새로 생성) | 배치/부품별 사진, 구분(장입·결과·컨트롤러·로그·기타) |
| `ActivityLog` | 누가 언제 무엇을 했는지 (새로 생성) | 등록·수정·사진·삭제 기록 |
| `Lookups` | 소재·판정·소결로 목록 | 드롭다운 목록으로 사용 (시트에서 항목을 추가하면 바로 반영) |

배치 번호: `SB-260925-01` · 부품 번호: `SB-260925-01-P01`
사진은 드라이브 `GAUSS 소결 사진` 폴더에 저장됩니다. 휴대폰 사진은 올리기 전에 1800px로 줄여서 빠르게 올라갑니다.

## 화면

- **목록**: 배치별 최고온도·유지시간·분위기·부품 판정·평균 수축률·사진 썸네일·상태. 소재/상태로 거르고 검색.
- **상세**
  - 기본 정보 (일자·소결로·작업자·소재·잉크 Lot·노 내 위치) + 개시 전 체크 3개
  - 분위기·가스 + **가스 예산 자동 검산** (여유율 1.5배 미만 빨강, 2.0배 미만 노랑)
  - 소결 프로파일 (구간별 목표온도·승온시간·유지시간, ℃/min 자동) · 이전 소결 조건 불러오기
  - 장입 부품 (출력 작업에서 고르면 이름·모델 치수가 들어감 → 소결 전/후 실측 → 수축률 자동)
  - 사진·파일, 결과 요약, 메모
- 티타늄·니오븀에 수소 가스를 고르면 경고, 퍼징 3회 미만이면 경고.

## 설치 (15분)

`소결 데이터` 시트에 이미 붙어 있는 스크립트(슬라이서 자동 등록용)와 섞이지 않도록 **별도 프로젝트**로 만듭니다.

1. https://script.google.com 접속 → **새 프로젝트**. 이름: `GAUSS 소결 기록`
2. `Code.gs` 내용을 지우고 이 폴더의 `Code.gs` 전체를 붙여넣기
3. 왼쪽 `파일 +` → **HTML** → 이름 `Index` (확장자 없이) → 이 폴더의 `Index.html` 전체를 붙여넣기
4. 저장(Ctrl+S) → 위쪽 함수 선택에서 `setup` → **실행** → 권한 승인
   (확인되지 않은 앱 → 고급 → 이동 → 허용). `소결 데이터` 시트에 `Photos`·`ActivityLog` 탭과 추가 열이 생기면 성공
5. **배포 → 새 배포 → 웹 앱** / 실행 계정: **나** / 액세스: **나만** (직원도 쓰면 *Google 계정이 있는 모든 사용자*)
6. 나온 URL을 크롬으로 열고 `⋮ → 캐스트, 저장, 공유 → 페이지를 앱으로 설치` → 바탕화면 아이콘 생성
7. 휴대폰에서도 같은 URL을 열어 홈 화면에 추가하면 소결로 앞에서 바로 촬영해 올릴 수 있습니다

`setup` 에서 "「소결 데이터」 시트를 열 수 없습니다"가 나오면, 시트 소유 계정에서 편집 권한을 받거나
`Code.gs` 맨 위 `SHEET_ID` 를 `''` 로 비우고 새 구글시트의 `확장 프로그램 → Apps Script` 에 붙여 넣으면
그 시트에 같은 구조를 만들어 씁니다.

## 코드를 고친 뒤

`배포 → 배포 관리 → 연필 → 버전: 새 버전 → 배포` 하면 같은 URL로 갱신됩니다.
