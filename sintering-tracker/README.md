# 소결조건 기록 프로그램 (구글시트 기반)

가스 소결로 SOP(`0. 장비 구성` ~ `9. 런 기록 양식`)를 그대로 데이터화한 웹 폼입니다.
Lot No 기록표와 같은 방식으로, 구글시트를 DB로 쓰고 Apps Script 웹앱을 폼 화면으로 씁니다.
링크를 바탕화면 바로가기로 깔아두고 매 런마다 입력하면 됩니다.

## 구성
- `Runs` 시트: 런 1건당 1행 (가스/퍼징/차단벽/도어체결/결과/사진링크 등)
- `Steps` 시트: 런별 소결 프로그램 스텝 (목표온도 / 승온시간 / 유지시간)
- 사진은 구글드라이브의 `소결로_런사진` 폴더에 자동 저장되고, 시트에는 링크만 남습니다.

## 설치 (5분)

1. 구글드라이브에서 새 **구글 스프레드시트**를 만듭니다. (예: "GAUSS 소결조건 기록")
2. 메뉴 `확장 프로그램 > Apps Script` 클릭
3. 기본 생성된 `Code.gs` 내용을 지우고, 이 폴더의 `Code.gs` 내용을 그대로 붙여넣기
4. 왼쪽 `+` 버튼으로 **HTML 파일** 추가, 이름을 정확히 `Index` 로 지정
   (`Index.html`이 아니라 `Index` 입니다 — Apps Script가 확장자를 자동으로 붙임)
5. 이 폴더의 `Index.html` 내용을 그대로 붙여넣기
6. 저장(Ctrl+S)
7. 우측 상단 `배포 > 새 배포` 클릭
   - 유형: **웹 앱**
   - 실행 계정: 나
   - 액세스 권한: **나만** (회사 내부 전용이면 이것으로 충분, 여러 명이 쓰면 "Google 계정이 있는 모든 사용자"로 변경)
8. 배포 후 나오는 **웹 앱 URL**을 복사
9. 처음 실행 시 권한 승인 화면이 뜨면 "고급 > (프로젝트명)로 이동 > 허용" 진행

## 바탕화면 바로가기 만들기
- 크롬/엣지에서 웹앱 URL 접속 → 브라우저 메뉴 > "바로가기 만들기" (또는 즐겨찾기 후 바탕화면으로 드래그)
- 만들어두면 앱처럼 클릭 한 번으로 폼이 열립니다.

## 코드 수정(개발) 시
- 시트를 여러 대 PC/휴대폰에서 같이 쓰려면 액세스 권한을 "Google 계정이 있는 모든 사용자"로 변경
- 스텝 항목이나 결과 항목을 추가하고 싶으면 `Code.gs`의 `RUNS_HEADER`/`STEPS_HEADER`와
  `Index.html`의 해당 입력 필드를 같이 수정 후 다시 배포(`배포 > 배포 관리 > 수정 > 새 버전`)하면 됩니다.
